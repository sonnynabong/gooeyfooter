# CSS Sticky Bubble Effect

A pure CSS recreation of the **Awesome Sticky Bubble Effect** from this [Medium article](https://medium.com/@rocchokcoco/css-awesome-sticky-bubble-effect-d2cc23241153) by ChokCoco.

> ⚠️ **Note:** This project is just for fun and for testing purposes. It's a demonstration of CSS filter effects and animations.

## What it does

Creates a mesmerizing bubble animation at the bottom of the page where multiple bubbles rise up and merge together using the `filter: contrast()` and `backdrop-filter: blur()` technique.

## Files

- `index.html` - Interactive bubble effect with color selector
- `flames.html` - Flame version using the same concept
- `README.md` - This file

## How it works

The magic happens through:
1. **Contrast filter** on the parent container
2. **Blur filter** on the bubbles
3. When blurred edges meet, they fuse together creating a "sticky" effect
